# Visual design-rules review: todo and fixes (2026-10-27)

Every screen of the web app was captured at 375 px and 1440 px (`apps/web/e2e/visual-audit.spec.ts`, run with `VISUAL_AUDIT=1`) and reviewed against the ux-ui design rules pack: sizes, element placement, spacing, weight and size hierarchy, contrast, and where, when and what each screen asks the user. Each row below is a finding with the rule it breaks, the fix, and its status. Shared-component rows that page reviewers raised are tracked in the last section.

Re-run the screenshots with:

```sh
cd apps/web && VISUAL_AUDIT=1 VISUAL_AUDIT_OUT=/tmp/shots npx playwright test e2e/visual-audit.spec.ts --project=chromium
```
